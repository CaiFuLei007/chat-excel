
# 会话管理以及用户业务逻辑实现

**系统身份** : 你是一个资深的 C++ 开发工程师 , 熟悉后端开发中业务逻辑的实现

**任务** : 完成用户子服务的会话管理 , 以及用户业务逻辑的实现

## 1. 会话管理

1. 定义 SessionManager 类 , 包含在 chat_excel::user_service 命名空间中
2. 头文件 session_manager.h , 源文件 session_manager.cpp , 放在 chat-excel/svc_user_service 路径下
3. 包含 SessionData 和 UserData 的智能指针, 用户操作会话表和会话缓存
4. SessionManager 类涉及到的操作如下 : 
	1. 创建会话 , 创建会话 ID 使用 <cpp-toolkit/util.h> 中封装的接口进行创建, 具体步骤如下 : 
		1. 创建会话结构体
		2. 将会话结构体存储到 数据库 和 Redis 中
	2. 检查会话是否有效, 具体步骤如下 : 
		1. 检查 Redis 缓存中是否存在会话 , 如果没有再查找 MySQL 数据库中是否存在
		2. 通过 会话中的用户 ID  , 获取用户信息 , 检查用户状态是不是上线
	3. 删除会话, 具体步骤如下 : 
		1. 先删除 MySQL , 再删除 Redis
	4. 通过用户 ID 获取用户信息
		1. 先读取 Redis ,如果没有再 查找 MySQL , 并将数据写到 Redis
		2. 返回用户信息

## 2. 用户业务

1. 定义 UserBusiness 类 , 包含在 chat_excel::user_service 命名空间中,负责管理用户业务逻辑
2. 头文件 user_business.h , 源文件 user_business.cpp , 放在 chat-excel/svc_user_service 路径下
3. 成员如下 :
	1. SessionManager 智能指针 , 用于操作会话信息
	2. VerifyCodeData 智能指针,用于操作验证码信息
	3. UserData 智能指针,用于操作用户信息
	4. <cpp-toolkit/rpc.h> 中的 ChannelManager 智能指针, 用于操作RPC通道
	5. 所有成员变量的初始化必须在UserBusiness构造函数中进行,但具体实例其他位置传入
4. UserBusiness 类涉及到的操作如下 : 
	1. 检查用户昵称是否唯一
	2. 检查用户邮箱是否唯一
	3. 用户注册 (调用该接口之前 , 已经检测昵称和邮箱是否唯一了) , 具体实现流程如下 : 
		1. 构建用户结构体 , 通过 <cpp-toolkit/util.h> 中的 uuid 生成器接口来创建用户 ID
		2. 密码要进行加密 , 使用bcrypt单向哈希算法加密,使用梅森旋转数生成器生成随机盐值,必须考虑线程安全问题
		3. 将用户信息保存到数据库中
	4. 密码登录 , 具体实现流程如下 : 
		1. 通过用户昵称获取用户信息 , 如果获取失败 ,再通过用户邮箱获取用户信息
		2. 检测用户密码是否正确
		3. 为该用户新建会话
		4. 将用户信息中的用户状态设置为 online 上线
		5. 更新 MySQL , 删除 Redis
	5. 验证码登录 , 具体实现流程如下 : 
		1. 通过验证码 ID 从 Redis 中获取用户的验证码
		2. 检查 验证码 ID , 验证码 , 用户邮箱是否都匹配
		3. 为该用户新建会话
		4. 将用户信息中的用户状态设置为 online 上线
		5. 更新 MySQL , 删除 Redis
	6. 会话登录  ,  具体实现流程如下 : 
		1. 通过会话 ID 获取用户 ID
		2. 通过用户 ID 获取用户信息
		3. 将用户信息中的用户状态设置为 online 上线
		4. 更新 MySQL , 删除 Redis
	7. 生成验证码, 具体实现流程如下 : 
		1. 生成一个随机的6位纯数字
		2. 创建验证码结构体 , id 使用<cpp-toolkit/util.h> 中的 uuid 生成器接口来生成
		3. 将验证码存储到 Redis 中 
		4. 返回验证码 ID
	8. 退出登录 , 具体实现流程如下 : 
		1. 通过会话 ID 获取用户 ID
		2. 通过用户 ID 获取用户信息
		3. 将用户信息中的用户状态设置为 offline 下线
		4. 更新 MySQL , 删除 Redis
		5. 删除当前会话
	9. 获取用户信息 , 具体实现流程如下 : 
		1. 通过会话 ID 获取用户信息
		2. 先通过会话 ID 获取用户 ID , 再通过用户 ID 获取用户信息
		3. 先找 Redis , 再找 MySQL
		4. 返回用户信息

## 3. 注意事项

1. 保存到数据库中的密码要进行加密 , 使用bcrypt单向哈希算法加密,使用梅森旋转数生成器生成随机盐值,必须考虑线程安全问题
2. 使用 <cpp-toolkit/util.h> 中封装的 JsonUtil 来进行序列化和反序列化
3. 程序中异常情况优先使用异常 , 已经对异常进行了封装在 chat-excel/common/exception.h 下 , 必须按照该文件中的说明定义和使用
4. 使用 <cpp-toolkit/logger.h> 中封装的 spdlog 接口进行日志的输出打印
5. 密码登录时,username 中可能是用户昵称,也可能是用户邮箱,如果能通过用户昵称获取到用户信息,就使用用户昵称登录；如果能通过用户邮箱获取到用户信息,就使用用户邮箱登录
6. 对于逻辑相同 , 重复性的代码逻辑进行封装, 提升代码的可复用性
